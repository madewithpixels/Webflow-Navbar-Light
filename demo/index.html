Install / the two-click version

Copy Navbar Light from the MWP Component Library and paste it into your project. Keep its one native Navigation panel: desktop and mobile share the same links, because duplicating your menu is how haunted websites begin.

OPTION A → self-contained Embed

Configure / the fiddly bit

At the Base breakpoint choose when it collapses, then pick dropdown, drawer or overlay and a motion preset. Style the existing mwp-css-nav_* classes in Designer. Leave the data hooks alone; they are shy and structurally important.
