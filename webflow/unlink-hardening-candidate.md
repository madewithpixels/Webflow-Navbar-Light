The v0.2.6 [release record](v0.2.6-release-verification.md#library-global-styles) establishes that the Library shares `All Links` (`color: inherit; text-decoration: none`) and `Body (All Pages)` (background, font, colour, size and line height). The native navigation classes deliberately leave font family and text colour to the destination cascade. On this Smashburger Preview, the fresh Never copy computed to Arial and `rgb(51, 51, 51)` on its Brand and panel link, matching the body's computed family and colour; both links had no underline. This confirms a live inheritance dependency in this destination. It does not isolate which imported tag rule supplied each computed value, or show how a brand-new destination with different tag styles would render. Preserve both tag styles during candidate work; Asset settings cannot exclude them.

Before considering a shared Library replacement:

1. All five selected-mode fresh unlinks produced zero numbered variants in this one destination. The Tablet-unlinked copy matched the linked trial in normal Preview and CSS/native fallback for all five choices after changing `data-collapse`; the separate Always, Never and Mobile-selected unlinks passed their post-refresh breakpoint and interaction checks. Repeat the class inventory on a fresh unlink from the eventual shared source and at a clean destination before treating this as a release guarantee.
2. Decide how to expose the Canvas open control in a distributable component. The direct root `data-canvas-open` attribute works after unlink; the local trial keeps it static to avoid the legacy binding problem. Any future grouped property must leave an equally obvious, functioning local control after unlink.
3. Confirm the generated class count on a fresh unlink from the eventual shared source definition and inspect tag-style dependencies at a clean destination. The site-local proof with zero numbered variants is strong evidence for this fixture, not a guarantee across other sites or Webflow revisions.
4. Resolve or explicitly accept the script-free visibility of `Smashburger settings` blocks on older copies. The all-mode trial's fixture-only CSS hides them without JavaScript. Focus return, `aria-expanded`, panel `aria-hidden`/`inert`, root overflow and backdrop state passed on the latest local linked/unlinked trial in Preview; repeat on a clean destination before release.
5. Preserve the native Details opening/closing, semantic links, accessibility state, and the `All Links`/`Body (All Pages)` tag styles. Seek separate authorization before sharing, publishing, pushing or tagging.
