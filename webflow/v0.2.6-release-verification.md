# v0.2.6 release verification

Recorded 2026-10-08 by Codex. Reviewed release commit `38bbf47`, annotated tag
`v0.2.6`. Michael authorised the push and consumer rollout in this session.

## Changes

- Overlay trigger retains its authored header position through opening and closing.
- A collapsed Overlay enforces vertical panel rows and clears anchored-panel
  centring translation. Expanded desktop panels retain their authored layout.
- Preset Overlay panels clear inherited desktop border radii.
- Packaged social/contact Image icons follow link colour through their alpha
  silhouette. `data-icon-mode="original"` preserves artwork; Layout presets Off
  also disables automatic tint. Inline SVG contact icons remain native.
- The Canvas helper hides the script Embed placeholder bar in Designer.

## Library global styles

The shared update also listed All Links and Body (All Pages) as Added. Source
MCP inspection found `a { color: inherit; text-decoration: none }` and a `body`
tag style defining background, font, colour, size and line height. Imported copies
exist in Smashburger, Voice Focus, madewithpixels and Lattice; the current read
does not establish when each copy was installed. Michael reported no visible
regression. These styles were preserved rather than removed without a cascade
baseline. Component packaging should be reviewed before offering a clean install
to new consumers.

Codex's earlier suggestion that Asset settings could exclude these tag styles
was incorrect: that control configures shared asset folders.
